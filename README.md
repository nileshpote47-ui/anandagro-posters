या folder मधले poster दर रविवारी आपोआप तयार होतात आणि Instagram वर post होण्यासाठी वापरले जातात.
Post फक्त Google Sheet मध्ये Status "Ready" केल्यावरच होते.

- `posters/` तयार poster (1080x1350 JPEG)
- `specs/` प्रत्येक आठवड्याच्या poster चा मजकूर
- `render.py` poster बनवण्याचा script
- `WEEKLY.md` दर आठवड्याच्या कामाचे नियम
